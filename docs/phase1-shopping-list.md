## 2. 接口分配（买之前就确认好够用）

哪吒Pro 有 **J1–J4 四个数字 / 模拟口**，另有几个 **IIC（蓝色）口**，以及 **M1–M4 四个电机口**。按钮、碰撞开关、数码管都要占 J 口，OLED 走 IIC 口，所以下面正好用满 J 口：

| 接口 | 接什么 | MakeCode 积木（扩展名） |
|---|---|---|
| **M1** | 智能积木电机（升降） | `nezhaV2`（扩展 `pxt-nezha2`） |
| **J1** | 按键模块①：红=1F，蓝=2F | `PlanetX`：按键 J1 红色 / 蓝色 被按下 |
| **J2** | 按键模块②：红=3F，蓝=开门（预留） | 同上，选 J2 |
| **J3** | 碰撞传感器①：井道底部，**归零** | `PlanetX`：碰撞传感器 J3 被按下 |
| **J4** | 碰撞传感器②：轿厢底板下，**超载** | 同上，选 J4 |
| **IIC** | OLED 显示屏 | `PlanetX`：OLED 显示 |
| micro:bit 本身 | 5×5 点阵显示大号楼层数字和箭头；扬声器"叮"；A/B 键做急停 / 复位 | 内置 |

> J 口全部用完。第二阶段要加更多数字传感器时，可以把 micro:bit 的 A/B 键接管 3F 和开门，空出 J2；或者换成 IIC 接口的传感器。

## 3. 收到货后的验证与调试顺序

### 3.1 第一天：先验证"链路通不通"，不搭电梯

- [ ] 哪吒Pro 用 Type-C 充满电
- [ ] iPad 装 **micro:bit 官方 App**，跟着 App 配对 micro:bit
- [ ] 写一个"按 A 显示 1、按 B 显示 2"的程序，**蓝牙上传成功**
- [ ] 在 MakeCode 里添加扩展：搜 **`nezha2`**（或粘贴 `https://github.com/elecfreaks/pxt-nezha2`），再搜 **`PlanetX`**（`https://github.com/elecfreaks/pxt-PlanetX`）
  - 两个都是 ELECFREAKS 官方扩展，`pxt-nezha2` 已列入 MakeCode 官方审核通过的扩展。但**在 iPad App 里能否正常加载和编译，仍要当天实测**。不行就先用电脑浏览器打开 makecode.microbit.org
- [ ] 电机插 M1，拖"设置 M1 以 30% 速度正转 360 度"，看它是不是正好转一圈
- [ ] 显示"M1 相对角度值"，用手转电机轴，看数字跟着变

### 3.2 让一一算一算：电梯会跑多快？

```text
电机转速 125 圈/分 ≈ 2 圈/秒（空载；带负载会慢一些）
经过蜗杆减速 → 卷筒转速 = 2 ÷ 齿轮齿数（蜗杆配 8 齿 = 8:1，配 24 齿 = 24:1）
轿厢速度 = 卷筒转速 × 卷筒周长

例：蜗杆 + 8 齿，卷筒周长 6 cm → 2 ÷ 8 × 6 ≈ 1.5 cm/秒 → 10 cm 一层约 7 秒 ✅
例：蜗杆 + 24 齿，同样的卷筒     → 约 0.5 cm/秒 → 10 cm 一层约 20 秒（有点慢）

每层需要的电机角度 = 层高 ÷ 卷筒周长 × 360° × 减速比
例：10 ÷ 6 × 360 × 8 = 4800°（先算，再实测修正）
```

> 这是很好的数学课：齿轮比、周长、速度 = 距离 ÷ 时间。最后以实测为准，因为绳子会越卷越粗。

### 3.3 搭建和编程顺序

1. **井道 + 轿厢 + 卷扬**：先只用手转，确认轿厢上下顺滑、不卡、不晃。
2. **归零**：程序开头让电机慢速下行，直到 J3 碰撞传感器被压下 → 停电机 → **"将 M1 相对角度清零"**。
3. **标定楼层角度**：把轿厢开到 2F、3F，记下"相对角度值"，填进程序里的列表 `[0, 2F角度, 3F角度]`。
4. **按钮呼叫**：J1 / J2 的按钮设置"目标楼层" → 电机转"目标角度 − 当前角度"度（正数上行、负数下行）。
5. **显示**：运行中 OLED 显示 `2F ↑`，点阵显示箭头；到站显示数字、播放"叮"。
6. **超载**：轿厢底板用橡皮筋撑起来，下面放 J4 碰撞传感器。放重物压到开关 → OLED 显示 `OVERLOAD`，按钮不响应。
7. **故障**：运行超过（实测时间 × 2）还没到 → 停电机，显示 `E`。

> 一个容易漏掉的细节：**J4 的线跟着轿厢上下跑**，要留足长度、顺着井道固定，别卷进齿轮。真电梯里这根线就叫"**随行电缆**"，可以讲给一一听。

## 4. 下单避坑

| ⚠️ | 说明 |
|---|---|
| **认准"哪吒Pro"（EF05070）** | 不要买老款"**哪吒扩展板**"（EF05043）。哪吒Pro 的 M1–M4 是给智能电机用的专用接口（UART 通信），老款按普通直流电机设计，用不了编码器方案。也不要买"哪吒A"（那是 Arduino 版） |
| **升降电机认准"智能积木电机"（EF05071）** | 同品牌还有"高速积木电机""360° 积木舵机"，它们**没有编码器**，做不了按角度停层 |
| **micro:bit 认准 V2** | 背面有麦克风和扬声器、标着 V2 的才对。不要买 V1.5 库存货；"micro:bit 兼容板"和其他品牌的仿制板不要买 |
| **只在品牌官方店或旗舰店买** | 淘宝 / 京东搜"**恩孚 哪吒Pro**""**ELECFREAKS 旗舰店**""**行星X 智能积木电机**"。拼多多上同名商品可能是转卖或旧款，**核对 SKU 编号（EF05070 / EF05071 / EF05017 / EF05008 / EF05016）再下单** |
| **问店家一句** | "传感器是否自带 RJ11 线？""组合里是否含 Type-C 线？"，避免收货后缺线 |
